#📌 Rahala 



Description du projet : Rahalla est une application de gestion touristique complète développée en JavaFX. Elle offre une suite d'outils pour la gestion d'événements, de restaurants, de matériels, de blogs, ainsi qu'un système de gestion des réclamations et des utilisateurs.



##🛠️ Technologies/utils utilisées





###🖥️ Application Desktop

JavaFX – Framework Java pour l'interface graphique (partie bureau)

IntelliJ IDEA – IDE utilisé pour développer l’application JavaFX

JDK 17+ – Environnement Java pour compiler et exécuter l’application


###🔙 Backend

Symfony – Framework PHP moderne, robuste et modulaire

PHP – Langage de programmation côté serveur

Doctrine ORM – Mapping objet-relationnel pour la gestion des entités et de la base de données



###🗃️ Base de données

//Pour symfony 

MySQL / MariaDB – Système de base de données relationnelle

PhpMyAdmin – Interface de gestion de base de données



//Pour JAVA et integration Symfony Java

AlwaysData (MySQL) – Hébergement distant de la base de données accessible par Symfony et JavaFX





###🎨 Frontend

Twig – Moteur de templates utilisé par Symfony

HTML5/ CSS / JavaScript

Bootstrap 5 – Framework CSS pour un design responsive

Fetch API – Pour les appels AJAX et les intégrations API



###🌐 APIs & Intégrations

API de traduction – Pour traduire dynamiquement les contenus

API QR Code (Endroid QR Code) – Génération de QR codes pour les réservations

PayPal API – Paiement en ligne sécurisé

Google reCAPTCHA – Protection contre les bots lors des formulaires

Chatbot API – Interaction automatique avec les utilisateurs

Google Maps API – Affichage des lieux de camping sur une carte interactive

Mailing API (Symfony Mailer / SMTP) – Envoi d’e-mails de confirmation et notifications

Voice Recording API – Enregistrement vocal intégré dans l’application

Face ID API (reconnaissance faciale) – Authentification biométrique des utilisateurs



###🔒 Sécurité

Symfony Security – Gestion de l’authentification, des rôles et des accès

Validation des entrées (Assert, Validator) – Protection des données utilisateur



###📦 Outils & Déploiement

Composer – Gestionnaire de dépendances PHP

Symfony CLI – Outils en ligne de commande pour gérer le projet

Git & GitHub – Versioning du code source

Visual Studio Code – IDE pour Symfony

IntelliJ IDEA – IDE pour JavaFX

AlwaysData – Hébergement distant
